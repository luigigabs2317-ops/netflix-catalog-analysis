# Dados brutos

Baixe o dataset **Netflix Movies and TV Shows** no Kaggle:
https://www.kaggle.com/datasets/shivamb/netflix-shows

Coloque o arquivo nesta pasta com o nome exato:

```
data/raw/netflix_titles.csv
```

O CSV original não é versionado (ver `.gitignore`). Os dados já tratados ficam em `data/processed/`.
